# Turbo Trail

A self-contained 3D browser kart racer built with Three.js. It has a closed spline circuit with rolling hills, banked turns and jump ramps; six detailed stylized karts; neon boost pads; drift mini-turbos; spinning item boxes; a race radar; and synthesized Web Audio effects.

## Run it

Serve this folder with a local static server and open its URL. Three.js and the procedural textures are included locally, so no network connection is needed. No package install or build step is required.

## Controls

- **Steer:** Arrow keys or WASD
- **Accelerate / brake:** Up and Down, or W and S
- **Drift:** Hold Space or Shift while turning; release for a mini-turbo
- **Use item:** E or Enter
- **Pause:** Escape
- **Touch:** On-screen steering, drift, accelerate and item buttons appear on narrow screens. Drag on the track to steer as well.

Item pickups randomly grant triple mushrooms, green shells, homing red shells, banana peels or a rainbow star. Race three laps against five rivals.

## Graphics

Rounded kart bodies and tires, alloy spokes, side vents, engine fins and numbered racing decals sit alongside layered tree canopies, petal flowers, corrugated guardrails and a detailed windmill. Shared 512px procedural textures add painted variation, grass blades, asphalt aggregate, bark grain, foliage, woven fabric, tire tread, masonry and roof tiles. Subtle bump mapping provides surface depth; instanced scenery and merged static kart parts keep draw calls contained.

# Turbo Trail

A self-contained 3D browser kart racer built with Three.js. It has a closed spline circuit with rolling hills, banked turns and jump ramps; six low-poly karts; neon boost pads; drift mini-turbos; spinning item boxes; a race radar; and synthesized Web Audio effects.

## Run it

Serve this folder with a local static server and open its URL. The page imports Three.js from jsDelivr, so the first load needs an internet connection. No package install or build step is required.

## Controls

- **Steer:** Arrow keys or WASD
- **Accelerate / brake:** Up and Down, or W and S
- **Drift:** Hold Space or Shift while turning; release for a mini-turbo
- **Use item:** E or Enter
- **Pause:** Escape
- **Touch:** On-screen steering, drift, accelerate and item buttons appear on narrow screens. Drag on the track to steer as well.

Item pickups randomly grant triple mushrooms, green shells, homing red shells, banana peels or a rainbow star. Race three laps against five rivals.

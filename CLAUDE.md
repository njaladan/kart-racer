# Agent instructions

## Commits and pushes

- Make and push self-contained commits frequently as you complete coherent units of work. Each commit should have a clear purpose, include everything needed for that change, and leave the project in a working state.
- Run the relevant checks before committing and use descriptive commit messages.
- Always push completed work to `main` before declaring a task done. Do not leave completed changes only in the local workspace or on another branch.
- Fetch the latest `origin/main` and integrate any new changes before pushing. Use a normal push; never force-push `main`.
- Include only changes belonging to your task and preserve unrelated work.
- If a push is blocked by permissions, branch protection, or a remote failure, report the blocker and the commits that remain unpushed.
